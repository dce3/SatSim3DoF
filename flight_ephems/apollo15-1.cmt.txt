This SPK file was made for Mert Davies (RAND Corp.) using new
Apollo 15 Lunar Command Module orbits created by Alex Konopliv (JPL)
as a result of his efforts to update the lunar gravity model.
Alex believes, however, that these new results will be essentially
the same as (no improvement over) the original orbit estimate results
as reflected in labels on the Pan Camera images.
 
Alex's NAVIO-format source files had 15 as the spacecraft ID, and did
not include a reference frame specification. The NIOSPK BODY_MAP
command was used to change the spacecraft ID to 915, and, based on
input from Alex, NGRPS was used to insert 'J2000' as the reference frame.
